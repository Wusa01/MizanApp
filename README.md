# ميزان | Mizan

**تطبيق لإدارة الأموال والحسابات الشخصية والتجارية، يعمل بالكامل على هاتفك ودون إنترنت.**

ميزان تطبيق أندرويد مبني بـ Flutter، يساعدك على تسجيل دخلك ومصروفاتك ومتابعة أرصدة حساباتك وصافي نتيجتك المالية من مكان واحد. بياناتك تبقى على هاتفك فقط، ولا يحتاج التطبيق إلى حساب أو اتصال بالإنترنت.

---

## ✨ المزايا

**المحاسبة**
- حسابات متعددة، شخصية وتجارية، مع رصيد افتتاحي لكل حساب.
- تسجيل الإيرادات والمصروفات والتحويلات بين الحسابات.
- التحويل بين حسابين لا يُحتسب إيراداً ولا مصروفاً، ولا يغيّر إجمالي الأرصدة.
- تعديل العمليات وحذفها مع تحديث الأرصدة تلقائياً.
- تصنيفات جاهزة للدخل والمصروفات، ويمكنك إضافتها وتعديلها وتعطيلها.
- تعطيل حساب أو تصنيف دون حذف عملياته السابقة.

**التقارير**
- لوحة رئيسية: إجمالي الأرصدة، الدخل، المصروفات، صافي النتيجة، ورسم بياني لآخر ستة أشهر.
- تقرير شهري مع التنقل بين الأشهر وتوزيع الدخل والمصروفات حسب التصنيف.
- تصدير التقرير الشهري إلى **PDF** بخط عربي.
- تصدير كل العمليات إلى **CSV** يفتح في Excel.

**الأمان والخصوصية**
- **بلا إنترنت:** لا يتضمن التطبيق أي كود شبكة، ولا يطلب إذن الإنترنت في نسخة الإصدار.
- **قفل التطبيق:** بالبصمة أو الوجه أو رمز الهاتف، ويُطلب عند الفتح وبعد 30 ثانية في الخلفية.
- **نسخ احتياطي مشفر:** ملف JSON محمي بكلمة مرور (PBKDF2 + AES-256-GCM)، ويكشف أي تعديل على الملف.
- **استعادة آمنة:** تتحقق من الملف أولاً وتنفَّذ كلها في معاملة واحدة، فلا تُفسد بياناتك إن كان الملف تالفاً.

**أخرى**
- تذكير يومي في وقت تحدده لمراجعة حساباتك.
- واجهة عربية كاملة من اليمين إلى اليسار.
- مظهر فاتح وداكن.
- العملة الحالية: فرنك CFA (FCFA).

## 📱 التثبيت على الهاتف

### الطريقة الأولى: ملف APK جاهز (الأسهل)

1. من صفحة **Releases** في هذا المستودع، حمّل أحدث ملف `app-release.apk`.
2. انقل الملف إلى هاتفك وافتحه.
3. إذا طلب النظام ذلك، اسمح بـ«التثبيت من مصادر غير معروفة» للتطبيق الذي فتحت منه الملف.
4. ثبّت التطبيق وافتحه.



### الطريقة الثانية: البناء من المصدر

#### المتطلبات

| المتطلب | الملاحظات |
|---|---|
| Flutter SDK | الإصدار 3.47 أو أحدث (Dart 3.14+) |
| Android SDK | مع أدوات سطر الأوامر (أو Android Studio) |
| JDK 17 | |
| هاتف أندرويد | الحد الأدنى يحدده Flutter، وعادةً أندرويد 7 فأحدث |
| كابل USB | للتثبيت المباشر |

على Ubuntu، تأكد أن كل شيء جاهز:

```bash
flutter doctor
flutter doctor --android-licenses
```

#### تجهيز الهاتف

1. الإعدادات ← حول الهاتف ← اضغط **رقم الإصدار** سبع مرات.
2. خيارات المطور ← فعّل **تصحيح USB**.
3. وصّل الهاتف بالكابل ووافق على نافذة «السماح بتصحيح USB».
4. تأكد أن Flutter يرى الهاتف:

```bash
flutter devices
```

#### التثبيت

```bash
git clone https://github.com/Wuas01/MizanApp.git
cd MizanApp
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter run --release
```

لإنتاج ملف APK تنقله وتثبّته بنفسك:

```bash
flutter build apk --release
```

يظهر الملف في `build/app/outputs/flutter-apk/app-release.apk`.

## ⚠️ مهم قبل أن تستخدمه

- **حذف التطبيق يحذف بياناتك.** البيانات مخزّنة على هاتفك فقط، ولا توجد نسخة سحابية. أنشئ نسخة احتياطية بانتظام من **الإعدادات ← إنشاء نسخة احتياطية مشفرة**، واحفظها خارج الهاتف.
- **كلمة مرور النسخة الاحتياطية لا يمكن استرجاعها.** إن نسيتها فلن تستطيع فتح النسخة.
- **ملف CSV غير مشفر.** عامله كأي مستند مالي، ولا تشاركه في أماكن عامة.
- **التحديث فوق نسخة مثبّتة** يتطلب أن تكون موقَّعة بنفس المفتاح. إذا بنيت من جهاز آخر فقد يرفض الهاتف التحديث، ولن يحل ذلك إلا حذف التطبيق، لذلك أنشئ نسخة احتياطية أولاً.

### إذا لم يصل التذكير اليومي

بعض الهواتف (Huawei وXiaomi وغيرها) توقف التطبيقات في الخلفية بقسوة. فعّل للتطبيق التشغيل التلقائي والتشغيل في الخلفية من إعدادات البطارية. التفاصيل لكل هاتف في [dontkillmyapp.com](https://dontkillmyapp.com). والتذكير غير دقيق للثانية وقد يتأخر دقائق.

## 🗂️ هيكل المشروع

```text
lib/
├── app/                  # التطبيق، التنقل، شاشة القفل
├── core/
│   ├── database/         # الجداول والمستودعات (المنطق المالي والنسخ الاحتياطي)
│   ├── services/         # التشفير، PDF، حفظ الملفات، القفل، التذكير
│   ├── settings/         # إعدادات المستخدم
│   ├── theme/
│   └── utils/
└── features/
    ├── dashboard/        # اللوحة الرئيسية
    ├── accounts/         # الحسابات
    ├── transactions/     # العمليات المالية
    ├── categories/       # التصنيفات
    ├── reports/          # التقارير
    └── settings/         # الإعدادات
test/                     # اختبارات المنطق المالي والنسخ الاحتياطي والتشفير
```

**مبادئ التصميم:** المبالغ تُخزَّن أعداداً صحيحة دون كسور، وكل منطق مالي (الأرصدة، التحويلات، التقارير) في طبقة المستودع المغطاة بالاختبارات وليس في الواجهة.
