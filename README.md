# ميزان | Mizan

**تطبيق ذكي لإدارة الأموال والحسابات الشخصية والتجارية**

ميزان هو تطبيق مالي مبني باستخدام Flutter، يهدف إلى مساعدة الأفراد وأصحاب الأنشطة التجارية الصغيرة على تنظيم أموالهم ومتابعة دخلهم ومصروفاتهم وأرصدة حساباتهم من مكان واحد.

يعمل التطبيق محلياً دون الحاجة إلى اتصال دائم بالإنترنت أو إنشاء حساب، مع التركيز على البساطة والخصوصية ودقة الحسابات.

## 🎯 أهداف المشروع

- تنظيم الحسابات المالية الشخصية والتجارية.

- متابعة أرصدة الحسابات بصورة دقيقة.

## 💰 النظام المالي

يعتمد ميزان على قواعد محاسبية واضحة:

**1. الرصيد الإجمالي**

مجموع الأرصدة الافتتاحية والإيرادات مطروحاً منها المصروفات.

**2. رصيد الحساب**

الرصيد الافتتاحي + الإيرادات - المصروفات + التحويلات الواردة - التحويلات الصادرة.

**3. صافي النتيجة المالية**

إجمالي الإيرادات - إجمالي المصروفات.

**ملاحظة:** التحويل بين الحسابات لا يُعتبر إيراداً أو مصروفاً، ولا يؤثر على صافي النتيجة المالية أو إجمالي أرصدة الحسابات.

تُخزّن المبالغ المالية كأعداد صحيحة لتجنب أخطاء الكسور العشرية.

## 🚀 تشغيل المشروع

### المتطلبات

- Flutter SDK
- Dart SDK
- Android SDK
- Git

### استنساخ المشروع

```bash
git clone https://github.com/Wusa01/mizan-.git
```

الدخول إلى مجلد المشروع:

```bash
cd mizan-
```

تحميل الاعتماديات:

```bash
flutter pub get
```

تشغيل التطبيق:

```bash
flutter run
```

### توليد ملفات Drift

عند تعديل جداول قاعدة البيانات:

```bash
dart run build_runner build --delete-conflicting-outputs
```

### فحص المشروع

```bash
dart format lib test
flutter analyze
flutter test
```

### بناء APK

```bash
flutter build apk --release
```

ستجد ملف APK في:

```text
build/app/outputs/flutter-apk/app-release.apk
```
